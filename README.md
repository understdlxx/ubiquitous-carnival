# 🏚 WAREHUS BOT

**بات دیسکورد پایتونی — استایل قدیمی دیسکورد، امنیت مدرن.**
سرور GTA SA-استایل خصوصی با چت، عکس، فان، انبار و بخش ادمین‌ها + سیستم کامل ضد ریید / ضد هک / ضد اسپم.

همه دستورات به دو شکل کار می‌کنند: **پریفیکس** (`!ban`) و **اسلش** (`/ban`).

## ✨ امکانات

| بخش | جزئیات |
|---|---|
| 🏗 ساخت سرور | با یک دستور `!setup` کل تمپلیت ساخته می‌شود (کانال‌ها، رول‌ها، تنظیمات امنیتی، پیام‌ها) |
| 🛡 ضد ریید | تشخیص موج جوین + بلاک خودکار اکانت‌های زیر ۷ روز + وریفای خودکار روی HIGHEST |

| 🤖 ضد بات ناشناس | هر باتی که خودت دعوت نکرده باشی → فوراً کیک + آلارم (ابزار شماره ۱ ناکرها) |

| 🚨 آلارم ربایشن | تغییر اسم/لینک اختصاصی سرور یا اعطای رول ادمین → آلارم فوری برای تو |
| 🔇 ضد اسپم | فلود، تکرار پیام، منشن‌اسپم، **بمب فایل** → تایم‌اوت خودکار |
| 💾 بکاپ/ری‌استور | اسنپ‌شات خودکار ساختار سرور + `!restore` → بعد از نیوک، کانال‌ها و رول‌ها ساخته مجدد میشن |
| 🔐 قفل بات | بات فقط به سرورهای خودت جواب میده؛ اگه توکن لو بره و کسی بات رو جای دیگه دعوت کنه → خودش ترک میکنه |
| 💥 ضدکرش | هیچ خطایی بات رو نمی‌کشه (گاردهای process-level سبک Wick) |
| ✅ وریفای | چنل `#verify` با دکمه (بعد از ری‌استارت بات هم دکمه کار می‌کند) |
| 📜 لاگ کامل | پیام حذف/ویرایش، جوین/لیو، بن، تغییر رول و نیک‌نیم، ویس و... در چنل‌های لاگ |
| 🔒 لاک‌داون | فریز کل سرور در چند ثانیه موقع حمله |
| ⚠️ وارن | ۳ وارن = میوت خودکار ۶۰ دقیقه |

| برگرداندن پرمیشن ارتقا یافته (revert) | ✅ | ✅ | ❌ |

| سیستم Heat (امتیاز تخلف) | ✅ | ✅ | ❌ |
| وایت‌لیست سروری (!trust) | ✅ | ✅ | ✅ |
| بکاپ + ری‌استور ساختار | ✅ | ❌ | ⚠️ فقط پولی |
| ضدریید سنی + سرج + RAID MODE | ✅ | ✅ | ✅ |
| ضداسپم کامل + ضداینوایت | ✅ | ✅ | ✅ |
| قفل بات به سرور خودت (autoleave) | ✅ | ✅ | ❌ |

## ۱️⃣ نصب روی سیستم خودت

نیاز: **پایتون 3.10 یا بالاتر** → [python.org/downloads](https://www.python.org/downloads/) (تیک *Add to PATH* را بزن)

```bash
pip install -r requirements.txt
python main.py
```

بعد از اولین اجرا، توکن را در `config.json` بگذار (قدم بعدی) و دوباره اجرا کن.

## ۲️⃣ ساخت بات و گرفتن توکن

1. برو به [discord.com/developers/applications](https://discord.com/developers/applications) → **New Application**
2. تب **Bot** → **Reset Token** → توکن را کپی کن (**به کسی نده، جایی پست نکن**)
3. همین تب، پایین صفحه — این دو تا **حتماً روشن باشند** (وگرنه بات خطا می‌دهد):
   - ☑️ **SERVER MEMBERS INTENT**
   - ☑️ **MESSAGE CONTENT INTENT**
4. تب **OAuth2 → URL Generator** → تیک `bot` و `applications.commands` → Permissions: **Administrator** → لینک را باز کن و بات را به سرورت اضافه کن

**توکن را کجا بگذارم؟**
- روی سیستم خودت: داخل `config.json` جلوی `"token"` بچسبانش
- روی گیت‌هاب: **هرگز داخل فایل‌ها نگذار** — فقط در **Secrets** (بخش ۴)

## ۳️⃣ ساخت سرور با بات

بعد از اینکه بات آنلاین شد، توی سرور بزن:

```
!setup
```

(یا `/setup`)

بات در چند ثانیه این‌ها را می‌سازد:

```
📥 GETTING STARTED   welcome · rules · verify · announcements · introductions · staff-list
🏠 PUBLIC            chat · images · fun · memes · off-topic · bot-commands
🏭 WAREHUS           warehouse · media-vault · resources
🎮 GTA SA            gta-chat · gta-clips · car-meet · server-status
🔊 VOICE CHILL       Chill Lounge · GTA Sessions · Car Meet · 💤AFK
🛡 STAFF ONLY        staff-chat · mod-logs · security-logs · server-logs
```

**رول‌ها:** 👑 Owner · 🛠 Admin · 🛡 Moderator · 🤝 Friend · Member · Unverified · Muted · Bots

**تنظیمات امنیتی خودکار سرور:**
- Verification Level → **High**
- Content Filter → همه اعضا
- نوتیفایشن پیش‌فرض → فقط @mentions
- کانال AFK با تایمر ۵ دقیقه
- `@everyone` بدون اجازه منشن @everyone، بدون TTS، بدون ترد
- اسلومود روی همه چنل‌های عمومی
- بخش STAFF ONLY فقط برای ادمین‌ها قابل دیدن
- چنل‌های warehouse و media-vault: آپلود فایل فقط برای Member به بالا

> ⚠️ **مهم بعد از setup:** رول بات را در تنظیمات سرور بکش **بالاترین جای لیست رول‌ها** تا ضد نیوک بتونه حتی ادمین‌های خائن رو هم کنترل کنه.

## ۴️⃣ هاست رایگان ۲۴/۷ با GitHub Actions 🆓

### قدم به قدم:

1. اکانت [github.com](https://github.com) بساز (اگه نداری)
2. **New repository** → اسم دلخواه (مثلاً `warehus-bot`) → **Public** → Create
3. همه فایل‌های پوشه بات را آپلود کن (**Upload existing files**) — فایل `config.json` را **آپلود نکن** (در `.gitignore` هست)
4. تو صفحه ریپو: **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `DISCORD_TOKEN`
   - Secret: توکن باتت
   - توکن فقط همین‌جا ذخیره می‌شود — **هیچ‌وقت داخل کد یا ریپو نمی‌رود و چیزی لو نمی‌رود** 🔐
5. تب **Actions** → اگه پیام داد، **I understand my workflows, go ahead and enable them** را بزن
6. از لیست ورک‌فلوها **Warehus Bot Uptime** → **Run workflow** → Run

**اختیاری (پیشنهاد میشه):** یه سیکرت دیگه هم بساز به اسم `OWNER_IDS` و آیدی عددی خودت رو بذار (مثلاً `123456789012345678`) تا سیستم امنیت بدونِ مالک کیه — وایلیست خودکار ضدنیوک برای خودت فعال میشه.

تمام! حالا:
- بات ~۶ ساعت اجرا می‌شود و هر ۶ ساعت خودکار ری‌استارت می‌شود (محدودیت خود گیت‌هاب است؛ فقط چند ثانیه قطع می‌شود)
- برای همیشه خودش خودش را راه می‌اندازد، دیگه کاری نداری
- توکن از `DISCORD_TOKEN` خوانده می‌شود و `config.json` هم اصلاً داخل ریپو نیست

### 🔐 امنیت اطلاعات تو (هیچی لو نمیره)

| چیه | کجاست | لو میره؟ |
|---|---|---|
| توکن بات | لوکال: `config.json` · گیت‌هاب: فقط در **Secrets** (encrypted) | ❌ هرگز |
| دیتابیس بات (`data/`) | فقط روی سیستم خودت / کش **خصوصی** Actions | ❌ هرگز |
| وارن‌ها و آیدی‌ها | داخل `data/` — توی `.gitignore` است | ❌ پوش نمیشه |

- `config.json` و `data/` در `.gitignore` هستند → با git هم اشتباهی پوش نمیشن
- کد بات هیچ‌وقت توکن را چاپ یا لاگ نمی‌کند
- توکن در GitHub Secrets رمزنگاری‌شده ذخیره می‌شود و در لاگ‌های Actions هم **مقدارش مخفی** می‌ماند
- روی هاست رایگان، دیتابیس در **کش خصوصی** Actions می‌ماند (کسی از ریپو نمی‌بیندش) و بعد از هر ری‌استارت ۶ ساعته برمی‌گردد — هیچ‌وقت داخل ریپو کامیت نمیشود

### 💡 ضد هکر بچه‌ها چی داره؟

- هر کسی (غیر از خودت) **حذف انبوه** کانال/رول، **بن انبوه** یا **کیک انبوه** بزنه → تایم‌اوت ۷ روزه + پاک شدن همه رول‌هاش
- **ترد انبوه** بسازه (thread spam) → تردها فوراً پاک + پنالتی
- **وب‌هوک مشکوک** بسازه (ابزار ریید @everyone) → وب‌هوک‌ها فوراً حذف + تایم‌اوت ۷ روزه
- کسی با رول ادیت‌شده یا رول جدید **پرمیشن خطرناک** (ادمین و...) بگیره → پرمیشن **برگردونده** میشه، رول سمی حذف میشه و سازنده‌اش تایم‌اوت ۷ روزه می‌گیره — حتی اگه ادمینِ هک‌شده باشه
- هر **بات ناشناس** که تو دعوت نکرده باشی → کیک فوری + آلارم
- **لینک اینوایت** توی چت → پاک + پنالتی
- سیستم **Heat**: تخلف تکراری = میوت سنگین ۲۴ ساعته
- کسی **رول ادمین** بگیره یا اسم/لینک سرور عوض شه → آلارم فوری توی `#security-logs`
- اکانت‌های تازه‌ساخت (زیر ۷ روز) اصلاً وارد نمیشن
- موقع ریید: وریفای خودکار روی HIGHEST + با `!lockdown on` کل سرور فریز
- مودهای خودت با `!trust` میتونی وایت‌لیست کنی (هیچ‌وقت پنالتی نمیشن)
- اگه یه نیوکی به هر طریقی رد شد → `!restore` کانال‌ها و رول‌ها رو **خودش دوباره می‌سازه**
- اگه توکن بات لو بره و کسی بات رو به سرور دیگه دعوت کنه → بات **خودش ترک می‌کنه** (قفل سرور خانه)

> 💡 نکته: روی هاست رایگان اگه یه زمانی دیدی چنل‌های لاگ جواب نمیدن، فقط دوباره `!setup` بزن — هیچی تکراری ساخته نمیشه و تنظیمات وصل میشه.

### ⚠️ دو نکته صادقانه:

- **قوانین گیت‌هاب:** Actions به‌صورت رسمی برای CI/CD است، نه هاستینگ. اکثراً با این روش مدت‌ها بدون مشکل کار می‌کنند، ولی اگه گیت‌هاب متوجه بشه ممکنه ورک‌فلوت رو محدود کنه. ریپو رو پابلیک نگه دار (مینوز رایگان بی‌نهایت می‌دهد) و توکن فقط در Secrets باشه — امنه.
- اگه یه روزی خواستی **بدون هیچ ریسکی** ۲۰۰٪ آنلاین باشه، بخش پرمیوم رو بخون 👇

## ۵️⃣ هاست پرمیوم (پایداری ۱۰۰٪) 💎

### گزینه ۱ — سرور مجازی (VPS)
ارزون‌ترین راه حرفه‌ای (Hetzner از ~۵ یورو/ماه، یا هر VPS ایرانی). بعد از آپلود فایل‌ها روی سرور:

```bash
cd /opt/warehus-bot
pip install -r requirements.txt
echo "DISCORD_TOKEN=توکن_اینجا" > .env
cp deploy/warehus-bot.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now warehus-bot
```

بات با `Restart=always` همیشه زنده می‌ماند — حتی بعد از کرش یا ریبوت سرور.
لاگ زنده: `journalctl -u warehus-bot -f`

### گزینه ۲ — پنل‌های هاست بات
سرویس‌های هاست بات دیسکورد (پنل‌های Pterodactyl) هم کار می‌کنند: فایل‌ها را آپلود کن، Startup را `python main.py` بذار، متغیر `DISCORD_TOKEN` را در تب Environment وارد کن.

## ۷️⃣ تنظیمات امنیت (`config.json`)

```json
"security": {
  "min_account_age_days": 7,      // اکانت زیر این روزها در دم کیک می‌شود (ضدریید)
  "join_surge_count": 6,          // چند جوین در چه بازه‌ای = آلارم ریید
  "join_surge_window_seconds": 60,
  "spam_messages": 7,             // چند پیام در بازه زیر = اسپم
  "spam_window_seconds": 5,
  "max_mentions_per_message": 5,  // منشن بیشتر از این = اسپم
  "max_attachments_per_message": 6, // بمب فایل = اسپم
  "duplicate_messages": 4,        // تکرار یک پیام
  "block_invites": true,          // لینک دعوت دیسکورد = پاک + پنالتی
  "heat_limit": 100,              // امتیاز تخلف تا میوت سنگین
  "auto_timeout_minutes": 60,     // مدت میوت خودکار اسپمرها
  "hard_timeout_minutes": 1440,   // میوت سنگین تکرارکارها (۲۴ ساعت)
  "nuke_threshold": 3,            // چند حذف/بن/کیک پشت سر هم = ضدنیوک
  "nuke_window_seconds": 30,
  "thread_nuke_threshold": 4,     // چند ترد در بازه = ترد-اسپم
  "allow_foreign_bots": false,    // بات ناشناس کیک می‌شود
  "backup_interval_minutes": 20,  // هر چند دقیقه بکاپ خودکار
  "warn_limit": 3                 // چند وارن = میوت خودکار
}
```

و دو کلید بیرونی مهم (لیست ID):
- `"allowed_guild_ids": []` — بات فقط به این سرورها جواب میده. **خالی بذاری، خودکار قفل به سرور فعلیت میشه** (ضد سوءاستفاده توکن). اگه بات رو به سرور دومت هم میخوای، IDش رو اضافه کن.
- `"allowed_bots": []` — ID بات‌هایی که خودت دعوت کردی و نباید کیک بشن. (رول `Bots` هم که ستاپ میسازه محافظت می‌کنه)

- مالک سرور، آیدی‌های `owner_ids` و لیست `!trust` هیچ‌وقت توسط ضدنیوک پنالتی نمی‌شوند.
- **تنظیمات را تغییر دادی؟** بات را ری‌استارت کن.

## ۸️⃣ رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `PRIVILEGED INTENTS ARE OFF` | پورتال توسعه‌دهنده → Bot → دو اینتنت SERVER MEMBERS و MESSAGE CONTENT را روشن کن |
| `TOKEN IS INVALID` | پورتال → Reset Token → توکن جدید را بگذار |
| بات آنلاین است ولی جواب نمی‌دهد | بات را دوباره با پرمیشن Administrator دعوت کن + رولش را بالای لیست بگذار |
